# 여기에 단어 파일을 올리세요

이 폴더에 `.txt` 또는 `.csv` 파일을 올리면 자료실 홈페이지에 자동으로 목록이 뜹니다.

## 파일 형식

한 줄에 하나씩, `단어,뜻` 형식으로 작성하세요.

```
apple,사과
banana,바나나
```

보카챌린지처럼 날짜가 정해져 있다면 맨 앞에 날짜를 붙이세요.

```
1,apple,사과
1,banana,바나나
2,cat,고양이
```

## 파일 올리는 방법

1. 이 저장소(vocab-word-sets)로 들어옵니다
2. `words` 폴더로 들어옵니다
3. "Add file" → "Upload files" 버튼을 누릅니다
4. 파일을 드래그하거나 선택해서 올리고 "Commit changes"를 누릅니다
5. 잠시 후 홈페이지(`index.html`)에 자동으로 목록이 뜹니다
